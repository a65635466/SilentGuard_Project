# Phase 05: 외부 전달과 시나리오 테스트

## 목표

검증된 알림만 전달하고, MVP에서는 외부 채널 미설정 상태도 정상적으로 표시한다.

## 해야 할 일

- [ ] `channel`, `status`, `sent_at`, `external_message_id`를 반환한다.
- [ ] MVP 기본 상태를 `not_configured`로 둔다.
- [ ] 일반 대화에서는 Agent 호출이 없음을 확인한다.
- [ ] 위험 대화에서 구간·사건·알림이 나오는지 확인한다.
- [ ] Agent 실패와 전송 실패를 각각 확인한다.

## 완료 조건

전송 상태가 분석 결과와 분리되어 표시되고, 실패해도 분석 결과가 삭제되지 않는다.
