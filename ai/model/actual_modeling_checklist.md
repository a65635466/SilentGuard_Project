# SilentGuard 실제 모델 인수 점검 체크리스트

이 문서는 다른 컴퓨터나 Colab/Kaggle/개인 폴더에 있는 실제 모델 작업물을 `ai/model/`로 가져오기 전에, 그 모델이 어디까지 진행됐는지 확인하기 위한 체크리스트다.

중요: 이 문서는 추천 데이터셋 기준으로 작성하지 않는다. 실제 모델이 이미 사용한 데이터셋, 전처리 방식, 특징 추출기, 학습 코드, 평가 결과를 확인해서 그대로 기록한다.

## 사용 방법

1. 실제 모델 작업물이 있는 컴퓨터에서 아래 항목을 하나씩 확인한다.
2. 확인된 것은 `[x]`로 체크한다.
3. 모르는 것은 `[ ]`로 두고, `확인 필요`에 적는다.
4. 파일을 가져오면 실제 경로를 적는다.
5. 모든 항목을 채운 뒤 “현재 진행 단계 판정”을 업데이트한다.

## 현재 진행 단계 판정

아래 중 현재 실제 모델 상태에 가장 가까운 곳에 체크한다.

- [ ] 0단계: 모델 작업물 위치만 있고, 데이터/코드/artifact 확인 전
- [ ] 1단계: 사용 데이터셋과 라벨 기준만 확인됨
- [ ] 2단계: 전처리 코드 또는 전처리된 데이터가 있음
- [ ] 3단계: 특징 추출기/embedding 생성 코드가 있음
- [ ] 4단계: 학습 코드가 있고 학습 실행 기록이 있음

## 12. SilentGuard 백엔드 계약과의 차이 확인

현재 백엔드가 기대하는 모델 역할:

```python
get_bullying_probability(messages) -> float
```

또는 현재 mock 기준:

```python
get_mock_bullying_probability(messages) -> float
```

백엔드가 기대하는 출력:

```json
{
  "bullying_probability": 0.91
}
```

- [ ] 실제 모델 입력을 `messages` 배열에서 만들 수 있다.
