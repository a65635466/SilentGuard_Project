# Pages

## `/` SilentGuard Local MVP

Entry: `front/index.html`

Dependencies:

- `front/index.html`
  - `front/style.css`
  - `front/app.js`

Key rendered areas:

- App header with product title and description
- Screen tabs for chat room and analysis result
- Chat room list, room creation form, notification email input
- Chat thread and message composer
- Demo scenario controls
- Analysis metric cards
- Risk segment section
- Manager alert section

The requested Notion report design is not a rendered in-app route. It is generated as Markdown by `ai/notification/notion_markdown.py` and opened through a Notion page link sent by email.
