# Routes

SilentGuard is a static single-page app.

| Route | File | Layout |
| --- | --- | --- |
| `/` | `front/index.html` | Static app shell |

## Key Screens

- Chat room screen: input room name, notification email, raw chat messages, sample scenarios.
- Analysis result screen: risk score, risk level, notification delivery status, risk segments, manager alert details.

There is no router config and no framework-level route tree.
